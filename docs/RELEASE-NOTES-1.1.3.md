# CarPlay 1.1.3

本版新增自定义背景与内置背景无损压缩，以下汇总近期版本的主要改进。

1. **有线重连**：改善 USB 网络较晚就绪时的连接恢复，减少数据线未拔插时重新连接失败的情况。
2. **通话音频恢复**：改善挂断或结束会话后的音频恢复，减少音乐停留在通话音频路径的问题。
3. **多指触控**：优化地图双指缩放与多指下滑菜单，减少触点跳动和误操作。
4. **整体 UI 优化**：统一字号、按钮、设置卡片和横竖屏布局，精简说明，改善底部操作区、搜索和弹窗的显示。
5. **车型背景**：提供冒险家、航海家、飞行家三种背景，保留原有冒险家风格，航海家和飞行家按 2022 款车型调整。
6. **安装包瘦身（新增）**：六张内置背景改用无损压缩，图片资源减少约 2.86 MB，原分辨率和画面细节保持不变。
7. **自定义背景（新增）**：在「设置 → 车辆 → 车型背景 → 自定义」选择自己的图片，同步用于首页、设置和连接页；支持更换图片，随时切回三个内置车型背景。

继续保留林肯仪表、方向盘、原车语音助手协作、导航压低音乐及现有连接功能。

支持 Android 7.1（API 25）及以上，包含 Android 8.1 车机。沿用既有包名与发布签名，版本代码为 79，可覆盖安装 1.1.2、1.1.3-rc1 至 rc3 并保留设置。

发布前验证包括完整 Android 回归、Release Lint、签名、APK 完整性与上传后下载核验；具体结果见本页发布验证记录。自动化验证不代表新增了手机或车机实测结果。
