# CarPlay 1.1.3-rc3

修复首页底部操作区在首次打开、横竖屏切换或系统栏变化后仍然悬空的问题。

- 首页改为使用本次窗口测量的可用高度，避免读取旧高度或系统配置中的较小高度。
- 断开连接／USB、设置及中间 CarPlay 装饰线作为整体，距安全区底边保留 12 dp；横竖屏规则一致。
- 窗口变化时同时更新内容测量，避免误判为矮窗口而切换左右分栏，或让圆环、主按钮与底部操作重叠。
- 保留网络名与密码连接、林肯三车型背景、现有设置和连接功能。

新增首次布局、窗口尺寸与系统配置不一致、旋转和系统栏变化的回归检查，覆盖 Android 10 与 Android 12；另检查连接状态切换、紧凑屏、大字体和从右到左布局。截图来自原生 Android 视图离屏渲染，华为手机与林肯车机仍需安装测试。

支持 Android 7.1（API 25）及以上。沿用现有包名和签名，可覆盖 1.1.3-rc2 并保留设置。
