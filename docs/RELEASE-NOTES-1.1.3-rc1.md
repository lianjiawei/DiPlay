# CarPlay 1.1.3-rc1

本次为测试版本，用于对照同一局域网的两种连接握手，以及检查设置与首页的界面精修。

- 同一局域网增加两种明确选项：默认的「复用当前 Wi-Fi（免密码）」和「兼容连接（输入密码）」。兼容连接恢复原来的 WPA2 网络资料与完整 CarPlay 握手，会通过蓝牙将所填网络名和密码发送给所选 iPhone。车机应先在系统中连接对应网络。
- 网络名仍可从系统 Wi-Fi 列表选择或手动填写。兼容方式的密码与网络名绑定；修改网络名会清空表单中的密码，实际网络名不匹配时阻止使用旧密码。取消不保存，保存后在下次连接生效。
- 首页移除底部重复的连接说明、版本卡片和额外 USB 按钮，保留主连接操作及底部断开连接、设置和品牌标识。授权入口保留在连接设置中。
- 设置顶部只保留单行「设置」，关于页移除大图标、重复说明和标题旁的独立说明图标。完整产品与许可说明保留在开源项目鸣谢详情中。
- 设置项统一名称、当前值、图标和行高，说明按需展开；同组相邻设置之间保留细分隔线，单项卡片和末项不加线。圆角、音量等滑杆改为点开调节，保留原有档位、实时效果及保存行为。原本会立即重连的开关增加确认。

## 局域网对照测试

在同一台 iPhone、同一台接收端和同一个路由器网络下，进入连接设置，选择「现有 Wi-Fi / 同一局域网」，打开「选择系统 Wi-Fi」，切换「连接方式」。先测试免密码复用，再测试兼容方式并填写当前网络的 WPA2 密码，每次保存后重新连接。请记录是否进入 CarPlay，并分别导出诊断报告。

现有报告表明：系统 Wi-Fi 已读取、蓝牙认证已通过，但免密码握手后没有 AirPlay TCP；同报告中的 Wi-Fi 直连曾建立会话。旧版填写密码能在该路由器工作，是握手回退的重要线索，尚不能证明 iOS 具体拒绝哪一个被省略的消息或字段。此测试包不预先宣称实机问题已经解决。

继续使用现有包名、签名和 Android 7.1（API 25）最低版本，兼容 Android 8.1。版本代码为 76，可覆盖安装 1.1.2 并保留设置。完整测试、签名和构建结果随 GitHub 测试版发布记录提供。
