# CarPlay 1.2.0

1.2.0 是视频性能与车机交互优化版本，并为更多林肯／福特原车仪表固件增加可选兼容链路。现有连接方式、仪表进度、音频修复和用户设置均继续保留。

## 更新内容

1. **降低视频链路的内存与解码压力**：视频帧改用有界复用缓冲区，减少不同分辨率、帧率和大关键帧场景下的临时数组分配、内存复制与垃圾回收抖动。加密、分片、H.264／HEVC、解码队列、画面切换和断开重连继续遵循原有数据边界，不会复用仍被消费者持有的缓冲区。

2. **增加林肯／福特仪表兼容模式**：在已经实车验证的 `INFO/STATE` 与稳定路口进度链路之外，可选发送原车导航生命周期、完整转向广播和 HUD Socket，供基础仪表导航不显示的固件使用。兼容模式默认关闭，开启后仍复用原有的路口身份、稳定距离和结束保护，不会另算一套进度。

3. **优化主页与连接操作**：主页左下角显示当前连接方式并进入对应连接设置，中央连接按钮始终使用已保存的连接配置。统一底部操作按钮的图标、文字居中和单行短文案，精简与设置无关的就绪状态和说明卡片。

4. **完善设置与弹窗布局**：精简设置页冗余标题和状态区域，隐藏暂不使用的设置向导入口，缩小重新连接提示并统一弹窗底部操作区。在林肯车机 1920×1080、超宽屏 1920×720、华为手机 2640×1200 和紧凑窗口下保持一致的暗色布局。

5. **闭环在线更新流程**：检查结果直接复用检查按钮反馈；发现新版本后可在更新弹窗内阅读可滚动的完整说明、下载并进入安装，不再要求返回设置页重复点击。历史版本选择、下载、安装权限和失败重试沿用同一套操作逻辑。

6. **精简安装包与语言范围**：应用固定支持简体中文和英文，首次安装默认简体中文；移除不再支持的语言资源与多套内置车型背景，只保留默认背景和用户自定义／恢复默认能力，降低安装包体积和后续测试矩阵。

## 安装与升级

- 支持 Android 7.1（API 25）及以上系统。
- 包名保持 `cn.manstep.phonemirrorBox`，沿用此前 1.1.x 正式版签名，可以覆盖安装并保留设置。
- GitHub Release 和国内更新源均提供 APK 与 `SHA256SUMS.txt`；应用下载后继续校验文件、包名和 Android 签名。
- “仪表兼容”默认关闭。基础仪表导航已经正常的车辆无需开启；不要同时使用 CarPlay 导航和原车百度地图导航。

## 验证说明

- 视频缓冲覆盖分配上限、跨消费者持有、加密与分片、不同编解码器、队列清理、画面切换、断开重连和异常输入。
- 仪表兼容覆盖开关隔离、原链路进度连续、导航开始与结束、短暂空帧、0 米占位、路口切换、HUD Socket 鉴权与端口占用。
- 设置与更新流程覆盖简体中文和英文，以及主要车机、手机、超宽屏和紧凑窗口布局。
- 正式发布执行仓库发布级单元测试、lint、Debug／Release 构建，并校验版本、包名、签名与 SHA-256。
