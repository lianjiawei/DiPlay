# CorsairPlay 0.2.26-precision.5

基于个人版 `0.2.26-precision.4`，选择性吸收上游 `0.2.27` 的四项修复，并调整正式包名。本版不是完整合并上游 `0.2.27`。

## 更新内容

- 更新检查、历史版本查询、APK 和校验文件下载优先使用通过验证的非 VPN 网络，避免请求走入 CarPlay VPN。
- 有线连接首次发送启动会话请求后，30 秒内未建立 AirPlay 会话就报告失败，交由既有重试机制恢复；会话建立或控制器退出时取消超时任务。
- 避免旧的重连定时任务拆掉同一轮尝试中已经恢复的连接；恢复后再次丢失仍正常重试。
- 软件 Opus 编码发生断言异常时丢弃当前帧并尝试重置编码器，让后续帧继续处理。
- 正式安装包名改为 `cn.manstep.phonemirrorBox`，与所提供的“第三代CarPlay”APK 包名相同。Debug 保留 `.hudtest` 后缀。

保留个人版已有的 5／50／500 米仪表距离精度、USB 重枚举恢复、PCM 与音频焦点修复、有界异步日志和更新进度弹窗。本次不包含上游的高德后台清理、音乐积压丢包、自动启动行为、光感兜底或备用更新服务器。

## 安装与在线更新

- 版本号为 `0.2.26-precision.5`，versionCode 为 `60`。更新源仍为 `lianjiawei/DiPlay` 的 GitHub Releases。
- APK 沿用个人版签名，并保留此前使用的 CarPlay 配件认证资源；没有导入参考 APK 的签名或代码。
- 从旧个人版 `com.corsairplay` 下载本版后，Android 会将其安装为另一个应用，旧版仍保留，原设置和权限不会自动迁移。
- 参考“第三代CarPlay”APK 虽然包名相同，但签名不同，不能直接覆盖安装。卸载原应用会清除该应用数据，请按实际需要处理。
- 安装本版后，后续版本保持相同包名、个人签名并提高版本号，即可覆盖升级并保留本版数据。
- 手动检查更新可立即查询发布结果；后台检查仍沿用原有调度，不保证发布后马上弹出提示。
