# CarPlay 1.1.9

1.1.9 汇总发布 1.1.8 之后已经完成并验证的林肯、福特车机适配。本版本不包含后续规划的视频缓冲复用改造；该性能优化将独立进入 1.2.0，避免与当前稳定版本混合。

## 更新内容

1. **提升原车仪表路口进度稳定性**：修复较远距离、导航通知与定时保活并发时旧距离晚到的问题，避免距离持续减小时进度条被误判为新路口并重新起算。保留换路口、重新规划、导航结束和断开重连的边界保护。

2. **修复状态栏模式下的 CarPlay 画面尺寸**：显示 Android 顶部状态栏时，仅为顶部状态栏保留空间，左右宽度继续按照全屏逻辑使用；状态栏尺寸晚到或发生变化时会重新计算投屏区域，避免左右白边和画面偏移。

3. **统一主页和设置页交互**：品牌 Logo 仅显示在主页左上角，设置、连接引导和诊断报告等子页面使用统一的左上返回操作。用户从连接设置主动连接后会立即回到主页显示连接进度，连接成功后继续进入 CarPlay。

4. **修复导航播报后的音频焦点状态**：完善导航播报结束、短暂语音输入和 CarPlay 媒体切换时的焦点释放与恢复，避免导航结束后媒体仍被压低。增加有界音频生命周期诊断，便于后续定位不同 iPhone 应用的暂停与恢复行为。

5. **修复诊断报告弹窗布局**：在窄屏、手机横屏和不同字体大小下统一操作按钮尺寸与排列，避免“分享”“完成”“查看”等按钮挤压、遮挡或错位。

## 安装与升级

- 支持 Android 7.1（API 25）及以上系统。
- 包名保持 `cn.manstep.phonemirrorBox`，沿用此前 1.1.x 正式版签名，可以覆盖安装并保留设置。
- GitHub Release 和国内更新源均提供 APK 与 SHA-256 校验文件；应用下载后仍会检查文件、包名和 Android 签名。

## 验证说明

- 仪表路口进度、状态栏画面尺寸、设置导航、诊断弹窗和音频焦点均包含对应的自动化回归与边界测试。
- 发布前执行仓库规定的完整单元测试、lint 和三个应用模块的 Debug 构建，并额外执行主应用 Release lint、签名构建、版本、包名、签名与 SHA-256 校验。
- 状态栏和设置页修复已经过此前实机截图与操作验证；本次正式发布不重复安装模拟器。
