# CarPlay 1.2.3

1. 新增可选的独立音乐窗口，展示专辑封面、歌词或歌名、播放进度及播放控制。窗口默认关闭，启用后需重新连接 CarPlay。
2. 优化音乐窗口的专辑背景、按钮和布局，增加更细的宽度档位与窄窗口适配，支持记住选择的宽度。
3. 改善播放信息变化时的封面保持，减少切歌后专辑封面消失的情况。
4. 优化设置变更后的有线重连：等待旧连接资源完成清理后再开始连接。
5. 新增长路名分段显示开关，默认关闭；启用后在林肯／福特仪表上轮流显示较长的导航道路名，不改变仪表歌词的投屏长度。
6. 精简设置页面中的技术状态信息和部分说明文字。

## 安装与已知情况

- 支持 Android 7.1（API 25）及以上系统，包名和正式版签名保持不变，可覆盖安装并保留设置。
- 百度导航曾出现仪表道路名显示 `null` 的反馈；最新测试包尚未针对这一现象进行实车复测，不能确认该问题已解决。
