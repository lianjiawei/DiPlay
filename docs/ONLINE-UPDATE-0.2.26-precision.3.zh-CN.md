# 在线更新弹窗与下载流程

版本：`0.2.26-precision.3`，versionCode 50；代码继续基于上游 0.2.26，保留此前 USB、PCM、焦点、仪表和距离精度修改。包名仍为 `com.corsairplay`，使用原个人签名。

## 使用方式

1. 后台检查发现新版本后，在应用首页弹出版本与更新说明，提供“下载更新／稍后”。每个版本自动提示一次，记录按个人更新源区分。
2. 点击下载后，同一个弹窗显示进度条和百分比。服务器未提供文件大小时显示不定进度；下载完成后继续显示校验状态。
3. 校验通过才显示“立即安装”，点击后打开 Android 系统安装界面，仍需系统确认。
4. 失败时显示错误及“重试”，失败文件不能进入安装流程。重试保留弹窗当前显示的版本，下载前仍重新查询服务器的最新版本。
5. 下载时可点击“收起”。在“关于”页点击下载／校验进度即可重新打开弹窗，不会新建第二个任务。当前 Activity 在后台时不弹窗，返回后可恢复原进度窗口。

下载沿用现有应用内任务，不提供跨进程的断点续传；应用进程被系统结束后需要重新发起下载。

## 防止回退的处理

- 自动提示只在首页前台、主窗口有焦点、没有 CarPlay 会话时出现。连接中的会话和已连接的会话均会阻止自动提示；连接启动任务排在提示之前。
- 用户关闭后台检查时不自动提示，手动检查和首页入口仍可用。
- 点“稍后”不会反复自动弹出相同版本；手动入口可以再次打开。
- 原有下载进度、待安装文件不会被首页更新提示覆盖。重复点击、后台结果更新或页面切换不会启动第二个下载任务。
- 保留下载前重新查询最新版本、SHA-256 校验、单次任务独立目录和失效回调检查。
- 保留车机兼容安装方式：由系统安装器处理安装授权，多个安装器时提供系统选择，不预先强制打开不兼容的未知来源设置页。
- 弹窗遵循应用主题；版本号在 RTL 语言中按完整的从左到右顺序展示。全部新增文案覆盖现有 8 种语言。

## 发布与检测前提

在线源仍为 `lianjiawei/DiPlay` 的 GitHub Releases。只有发布版本同时包含 APK 和 `SHA256SUMS.txt` 才会进入可下载列表；发布源码提交不会自动生成可检测的安装包。后台检查沿用每天一次及首次打开延迟检查的调度，用户也可在“关于”中手动检查。

旧版需先通过手动更新或下载 Release 安装此版，才具有新的自动提示与进度弹窗。相同版本不会提示更新；后续需发布更高版本。
