# CarPlay 1.1.2

- 统一设置卡片的说明图标布局：图标移到选项值旁边，与标题、选项值和箭头在同一条水平中线上，不再单独落到说明文字一行。
- 说明文字与标题在起始侧对齐，使用完整可用宽度；选项值可利用短标题留下的空间，减少不必要的换行。长文案在窄屏和大字体下继续完整换行显示。
- 说明图标采用 48 dp 点击范围，点击图标或说明文字查看详情，点击标题或选项值仍打开原设置。滑动、取消触摸时不弹出详情，长按查看说明的方式保留。

检查范围覆盖全部设置分类，以及横屏、竖屏、高密度、窄屏、大字体和阿拉伯语从右向左布局；包含 Android 7.1、8.1 的点击回归。具体测试及构建结果附在 GitHub 发布记录中。

版本代码递增为 75。继续使用原包名和发布签名，可覆盖安装 1.1.1 等现有新签名版本并保留设置。最低 Android 7.1（API 25），继续兼容 Android 8.1；本次没有新增真实手机或车机实测结果。
