# CarPlay 1.1.7

1. **连接与返回逻辑优化**：主页和连接状态统一在同一页面中显示，完善权限拒绝后的重试、断开后的返回及旧入口复用，减少重复页面和系统返回循环。

2. **在线更新优化**：优先通过自有镜像获取版本、安装包和校验文件，保留 GitHub 备用源。更新提示统一放在「设置 → 关于」，移除主页更新卡片，下载结果不会在返回主页后重新弹出。

3. **车型背景与品牌选择**：修复车型背景入口在更换品牌或自定义图标后消失的问题，保留已选择的背景。新增「设置 → 车辆 → 首页品牌」，可选择林肯或福特，首页只显示对应 Logo，切换无需重新连接。

4. **整体 UI 与交互优化**：固定应用深色外观，精简外观切换和设置右侧说明图标，原说明位置可直接操作设置；修复更新按钮裁切，改善超宽屏、高密度、大字体及状态切换时的布局稳定性。

## 安装与升级

- 支持 Android 7.1（API 25）及以上系统。
- 沿用 1.1.6 的应用包名和发布签名，可覆盖安装并保留设置。
- 旧版本仍使用 GitHub 直连更新地址；若旧版无法下载，可先手动下载本版本覆盖安装，后续更新即可使用新镜像。
- 福克斯测试壁纸单独提供，不包含在 APK 中；可通过「设置 → 车辆 → 车型背景 → 自定义」导入自己的图片。

## 验证范围

源码完整回归检查已通过：3691 项测试通过、1 项环境相关跳过，三个应用的检查与调试构建通过。本次发布额外核对正式 APK 的版本、签名、认证资源与文件校验和；真实车机和 iPhone 的长时间连接稳定性仍需实车验收。
