# CarPlay 1.1.1

- 保留冒险家原有背景及柔焦图，继续作为默认车型。航海家、飞行家背景按 2022 年中国市场车型的外观参考调整，保持同一场景与构图。
- “设置 → 车辆 → 车型背景”简化为单行入口，右侧显示当前车型；去掉重复标题、单行卡片及最后一项多余的内部横线。
- 车型仍为冒险家、航海家、飞行家三选一。点击“保存”切换并记住选择，点击“取消”保留原设置；选择纳入设置备份。

车型选择只改变首页、设置和连接页的背景，不改变配对、连接配置或林肯功能，不需要重连。横竖屏、大字体及阿拉伯语布局沿用现有适配。

版本代码递增为 74，包名与发布签名保持一致，可覆盖安装 1.0.0、1.1.0 及 precision.10 之后的版本并保留设置。最低 Android 7.1（API 25），继续兼容 Android 8.1。

发布前执行完整 Android CI、Release Lint、签名构建及 APK 完整性检查，精确结果附在 GitHub 发布记录中。本次没有新增真实手机或车机的实测结果。
