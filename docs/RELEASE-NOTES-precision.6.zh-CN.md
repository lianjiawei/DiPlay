# CorsairPlay precision.6

基于个人版 `0.2.26-precision.5`，取消发送给林肯／福特原厂仪表的文字 32 字符截取限制。

## 更新内容

- 原厂仪表导航路名、音乐标题／歌词不再由 DiPlay 截取前 32 个字符，完整文字发送给仪表。
- 长中文、跨原截取边界的表情符号，以及导航静默期间重复发送的路名均保留完整内容。
- 继续过滤换行、制表符、空字符等原有控制字符；普通文字、空格、标点和表情符号不受该长度限制。
- 空文本处理、音乐仅发送标题／歌词而不拼接歌手的行为保持不变。

此修改保证 DiPlay 发出的文字完整，不保证原厂仪表完整显示。仪表自身仍可能因界面宽度、固件或协议限制而截取文字或显示省略号。DiPlay 自绘导航卡片和音乐卡片的显示布局、BYD 独立文字通道的字节限制均未调整。

保留上一版四项上游修复、个人版 5／50／500 米仪表距离精度及其他既有功能。本版不是完整合并上游 `0.2.27`。

## 安装与在线更新

- 应用版本名、APK 文件名和发布标题省去上游版本前缀，统一使用 `precision.6`。为兼容已安装旧版的更新识别，本次 Git 标签保留为 `v0.2.26-precision.6`；新版本同时识别简短版本名和旧格式标签，避免安装后反复提示同一版本。

- 版本为 `precision.6`，versionCode 为 `61`，正式包名仍为 `cn.manstep.phonemirrorBox`。
- 沿用 precision.5 的个人版签名与 CarPlay 配件认证资源，可覆盖升级该版本并保留应用数据。
- 更新源仍为 `lianjiawei/DiPlay` 的 GitHub Releases；手动检查更新可立即查询，后台检查沿用原有调度。
- 更早的 `com.corsairplay` 个人版属于不同包名，不自动迁移设置和权限。参考“第三代CarPlay”APK 虽同包名但签名不同，不能直接覆盖。

发布前执行仓库要求的单元测试、三个 Debug 构建及 Lint，并执行 Release 构建、Lint、认证资源检查、签名和 SHA-256 校验。源码包与 APK 对应同一发布提交。
