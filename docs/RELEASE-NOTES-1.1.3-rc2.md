# CarPlay 1.1.3-rc2

同一局域网连接改为仅使用网络名和密码。1.1.3-rc1 的实机对照报告中，输入密码连续六次成功启动，免密方式始终未接入 AirPlay；本版移除免密选项及“兼容模式”名称，保留系统 Wi-Fi 名称发现和手动输入。

- 已保存的网络名和密码继续使用；未保存密码时引导补填，避免继续等待连接。
- 修改网络名会清空待保存的密码；取消不修改原设置，保存后下次连接生效。
- 诊断报告保存弹窗按内容显示，查看、分享、完成按钮在内容下方；同时检查同类短内容弹窗。
- 保留林肯首页、三款车型背景、有线连接、Wi-Fi Direct、通话音频恢复和多指触控。

支持 Android 7.1（API 25）及以上。沿用 1.1.2 / 1.1.3-rc1 的包名与签名，可覆盖安装。此为测试版本，尚需新包实机回归；旧版的成功报告不等于对新版或所有路由器的稳定性保证。
