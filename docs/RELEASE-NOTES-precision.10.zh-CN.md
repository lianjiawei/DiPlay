# CorsairPlay precision.10 · 系统 Wi-Fi 与主页修复

车机已连接 Wi-Fi 时，默认复用系统网络，不再要求在 DiPlay 中重复输入 Wi-Fi 名称和密码。

**本版开始使用新的 Android 发布签名。** 已安装 `precision.9` 或更早个人版时，需先卸载旧版，再手动安装本版；不能通过应用内更新直接覆盖。卸载会清除 DiPlay 应用设置，安装后需重新授权和配置连接。安装本版后，后续沿用新签名的版本可正常覆盖升级。

## 本轮变化

- “同一局域网”模式优先读取车机当前连接的 Wi-Fi 名称，复用其网络地址；不代替 iPhone 配网，也不向 iPhone 下发 Wi-Fi 密码。使用前请让车机和 iPhone 通过系统设置连到同一局域网。
- 增加系统 Wi-Fi 选择入口，显示当前连接、已保存网络和系统最近发现的网络。系统未提供列表或名称时，可打开车机 Wi-Fi 设置，也可手动填写备用名称。
- 保留车机连接其他 Wi-Fi 的能力：Android 7.1–9 可在明确点击“连接”后使用系统已保存信息，或输入密码连接；Android 10 及以上交给系统 Wi-Fi 设置处理。切换网络可能中断当前 CarPlay 连接。
- 保存局域网设置后，在下次连接时应用，并保留主动重连提示。
- 提高首页底部 CorsairPlay 文字的对比度，增加暗影，恢复文字左右两条装饰线，并适配窄屏、大字体和阿拉伯语布局。

## 验证与实车试用

- 源码完整单元测试：shared 1611 项、common 1767 项、home 6 项，共 3384 项通过。
- 页脚最终实现另通过 8 项布局回归；三个应用的 Debug Lint 与 Debug 构建通过。
- 检查紧凑窗口、完整窗口、大字体和阿拉伯语 RTL 的原生截图，包括 Wi-Fi 列表和密码连接弹窗。
- 保留主应用最低 Android 7.1（API 25）兼容要求，包括 Android 8.1 车机。

**新局域网流程尚未连接实际车机和 iPhone 验证。** 自动化测试确认该流程不会发送 Wi-Fi 配网凭据，但尚不能证明 iOS 接受新的仅地址握手。请重点试用同网连接、系统 Wi-Fi 名称读取、切换网络后的重连以及设置保留；其他连接模式继续保留。

## 版本与安装

- 版本名 `precision.10`，versionCode `65`，正式包名 `cn.manstep.phonemirrorBox`。
- GitHub 标签沿用 `v0.2.26-precision.10`，兼容个人版更新识别。
- 使用 2026-10-22 新建的个人 Android 发布签名，证书 SHA-256 为 `f91fee2f5331241e265fbbfeca6c60ef27201b9e19c55b91ec4b137c3af5eae0`。该签名与 `precision.9` 不同；新旧安装不能直接覆盖。
- CarPlay 运行认证资源继续沿用 `precision.9`，与 Android APK 签名分开管理。发布前核对签名证书、版本号、认证资源和 SHA-256。
- 新签名的后续维护与旧版换装说明见 [发布签名说明](RELEASE-SIGNING.md)。
- 普通源码 Debug 包使用独立的 `.hudtest` 包名；未明确提供运行认证资源时，它只能用于开发与界面验证。
