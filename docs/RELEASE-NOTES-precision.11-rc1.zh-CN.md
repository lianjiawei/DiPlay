# CorsairPlay precision.11-rc1 测试预发布

版本代码：66。主应用仍支持 Android 7.1（API 25）及 Android 8.1。

- 首页和连接页的文字区增加渐暗衬底与文字阴影，改善照片高光处的可读性。
- 连接页只显示一条简短指引，完整排障和手势说明可通过“连接帮助”查看。
- 固定连接圆圈和手机图标，只旋转圆圈上的发光弧段；遵循系统动画设置。
- 为窄竖屏和大字体预留顶部品牌标识空间，优先缩小装饰圆环。
- 蓝牙控制循环运行时显示“等待 iPhone 接入 CarPlay”，避免过早显示“正在打开”。
- 同一局域网的免密码启动请求保留当前系统 Wi-Fi 名称和接入地址，继续省略密码和入网配置消息。

## 连接问题的实测边界

precision.10 的诊断报告记录了 12 次认证成功、12 次启动请求，但没有一次
AirPlay TCP 接入，随后多次超时。用户确认两端使用另一台设备提供的热点，
因此不能归因于目标 iPhone 开启个人热点。

本候选保留此前省略的 Wi-Fi 名称，用于验证网络标识是否影响协商。
日志尚不能区分启动参数兼容性与热点客户端隔离／发现受限，**未确认修复连接**。
请在同一个外部网络复测，并保留新的诊断报告；也可使用普通路由器进行对照。
不需要在 DiPlay 输入已连接网络的密码，继续关闭 Wi-Fi 凭据下发。

## 安装

使用 precision.10 起的同一签名。安装了新签名 precision.10 的设备可覆盖安装，
无需卸载；更早的其他签名版本仍需按签名迁移说明处理。
这是 GitHub 测试预发布，连接效果与长时间稳定性仍待实机确认。
precision.10 继续作为稳定版，不会被此预发布替换。

## 验证

已完成 3,390 项单元测试的验证，以及 mobile、home、maphost 的 Debug
构建和 Lint、mobile 的 Release 构建和 Lint。首次全量运行中，一个新增 RTL
界面测试因测试清单未声明 RTL 支持而失败；修正测试环境后重跑该测试类的
5 项测试通过，其余测试沿用全量运行结果。原始测试报告与界面截图保存在本地，
本次 Release 仅提供 APK 和 APK 校验值；公开源码通过对应 Git 标签获取。

APK 已验证 Android 7.1／8.1 的签名兼容性、四种 ABI 与 16 KiB ZIP 对齐；
这些检查不替代车机上的连接实测。

此候选已占用 precision 编号 11；后续公开版本应继续递增编号和 versionCode，
以适配现有应用更新比较规则。
