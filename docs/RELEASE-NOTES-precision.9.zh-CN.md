# CorsairPlay precision.9 · UI 改版试用

按已确认的黑色林肯冒险家设计方向重新调整首页、连接状态、设置和弹窗，供实车试用。

## 本轮变化

- 首页使用蓝灰暮色、黑色林肯冒险家与冰蓝连接圆环，统一玻璃按钮和卡片风格；林肯专属背景仅用于现有林肯品牌预设，其他品牌身份保留。
- 连接中显示对应状态与旋转光环；主屏首帧到达后进入实际 CarPlay 画面，成功提示单独淡出，尊重系统减少动画设置。
- 重新调整设置导航、设置行、关于与更新页面的视觉层级，保留原有分类、搜索、操作入口及滚动访问。
- 精简重复说明，保留重连、权限、清理文件及错误提示。详细设置说明仍可通过说明入口或长按查看。
- 调整按钮间距、文字留白、同排高度和随高度变化的圆角。弹窗根据可用宽度和文字长度选择并排或上下排列，修复窄屏更新弹窗的文字裁切。
- 保留连接、USB、音视频、仪表输出、设置默认值、在线更新、存储清理与安装的现有逻辑。

## 验证与试用重点

源码通过 3344 项测试、9 组窗口及两档字号下 594 个页面状态的布局回归，并检查深浅主题、大字体和阿拉伯语 RTL 截图。发布前另外执行项目要求的完整检查、正式版 Lint、签名构建及 APK 校验。

请在车机上重点试用：首页与设置的文字/按钮是否协调，窄屏和大字体是否完整，连接光环是否流畅，以及连接成功进入 CarPlay 的过渡。自动化验证没有连接实际 iPhone，实车 GPU 流畅度和硬件连接表现仍以试用结果为准。

## 安装与更新

- 版本名 `precision.9`，versionCode `64`，包名 `cn.manstep.phonemirrorBox`。
- 沿用 `precision.8` 的个人签名及连接认证资源；发布前核对签名一致、版本号递增、运行资源一致和 SHA-256。可覆盖升级同签名个人版并保留设置，无需先卸载。
- GitHub 标签使用 `v0.2.26-precision.9`，兼容旧个人版的更新识别；应用、发布标题与 APK 文件名继续使用短版本名。
- 原“第三代CarPlay”参考 APK 虽然包名相同，但签名不同，不能直接覆盖安装。

设计稿、原生实装截图及逐页对照保存在仓库 `docs/ui-redesign/implementation/fidelity/`。APK、源码包及发布标签对应同一提交。
