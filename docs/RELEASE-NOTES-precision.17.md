# CorsairPlay precision.17

林肯版正式发布。功能与 precision.16-rc1 相同，版本代码递增为 72；沿用既有包名和发布签名，支持从 precision.10 及后续版本覆盖升级并保留设置。

## 本次正式发布包含

- 有线重连：iPhone 的 USB 网络晚就绪且尚未尝试建立连接时，补发一次启动请求，保留已有 USB 重枚举、已插线启动及超时保护。
- 通话音频恢复：挂断或关闭会话时撤销 DiPlay 的通话模式请求，让 Android 继续处理原车电话等其他音频持有者，避免音乐一直停留在通话音频路径。
- 多指触控：双指缩放保持手指身份及槽位稳定，在最后坐标释放；多指下滑菜单减少误点，并清理页面退出或重连前尚未发送的触摸。
- 界面精修：统一字号和按钮层级，修复玻璃按钮竖向接缝；横竖屏固定连接状态、圆环和底部操作区，改善设置搜索收起及弹窗按钮。
- Wi-Fi 连接：保留复用系统当前 Wi-Fi、发现网络名称以及支持的旧系统手动入网方式。实际连接方式仍需按车机和 iPhone 的网络组合选择。

保留林肯仪表、方向盘、原车语音助手协作、导航压低音乐、音量渐变和音乐时钟优化。悬浮球及 BYD DiYou 桌面入口修复未纳入本版。

## 安装与验证

- 最低 Android 7.1（API 25），继续兼容 Android 8.1；包含 arm64-v8a、armeabi-v7a、x86 和 x86_64。
- 正式版编号递增为 precision.17，使 precision.16-rc1 及更早的 precision 版本可被应用内更新识别为旧版本；发布附件包含 APK 与 SHA256SUMS.txt。
- precision.10 起的版本可直接覆盖安装，无需卸载；precision.9 及更早版本使用旧签名，需先卸载再安装，设置需要重新配置。
- 发布验证包括完整 Android CI、Release Lint、APK 签名、文件完整性和上传后重新下载核验。精确检查结果随 GitHub 发布说明附上。

当前自动化已覆盖连接、音频、触控、横竖屏及部分 API 25 / 27 行为；尚未收到 precision.16-rc1 在林肯实车上的完整回归反馈，正式发布不代表新增了实车验证结果。请重点确认不断线重连、挂断后音乐与导航恢复、地图双指缩放和三指菜单。

默认三指菜单可与双指缩放共存；若将菜单设置为两指，下滑手势仍会优先处理两指触摸。
