CorsairPlay 0.2.24-precision.2 修复与回归审查

基线：lincoln-0.2.20 / 78ec40dd。本次保持 com.corsairplay 包名，内部版本号升至 44，个人发布版本为 0.2.24-precision.2。

| 批次 | 修复 | 用于防止功能退步的验证 |
| --- | --- | --- |
| 静音恢复 | 将启动时从系统推断的静音与车机明确发送的静音分开；前者可以跟随系统恢复，后者仍由车机释放 | API 25/28/33 验证系统恢复、会话重新接入、车机静音保持、缺少参数的广播、重复音源事件仍通知仪表 |
| 音频处理 | PCM 按有界区间只处理一次，部分写入重试不重复衰减；增加处理前后峰值、有效增益、静音原因诊断 | 验证预缓冲、512 字节部分写入、扬声器通话不受音乐衰减和车机静音影响，以及 PCM 全零时诊断能指出原因 |
| 时钟与拥塞 | 将接收队列水位纳入调速约束，高水位时不再反向减速；拥塞期间冻结时钟学习 | 验证满队列、正常水位的慢速校准、既有漂移驱动用例，以及拥塞消退后恢复已学到的真实校准值 |
| 媒体键焦点 | 只有暂停成功才允许恢复；取消过期恢复任务，校验会话、焦点和用户播放意图 | 验证短暂失焦、重复失焦、重复 GAIN、解绑、手动暂停、暂停失败、暂停接受期间恢复焦点 |
| 仪表生命周期 | 定时维护不再跳过剩余信息；结束后统一清理导航和剩余值；剩余信息开关可以使缓存失效 | 验证 2.5 秒结束窗口、短暂重算路线不闪退、结束后重开导航、旧结束快照不能重画、开关无需新元数据即可生效 |
| 更新与资源 | 更新源改为 lianjiawei/DiPlay，清理旧来源的缓存并保留用户选择，识别个人 precision 修订号；补齐六种翻译和默认分支 CI 触发 | 验证缓存迁移、跨来源检查计时器、修订号大小比较、保持原有 beta/RC 比较策略、超大版本字段及原有翻译检查 |

审查时保留的行为边界：

- 不通过定时强制取消静音来掩盖问题；真正的车机静音键和电话通话保留其原有语义。
- 输入队列拥塞期间的调速补偿不会成为永久学得的硬件漂移值，正常水位的校准算法保留。
- 音乐 Unity 增益仍保持原始字节；已处理但尚未被 AudioTrack 接收的尾部不会再次乘增益。
- 指令在过期前被取消；没有发生实际暂停的焦点抖动不会触发恢复播放和轨道重建。
- 导航短暂空窗仍有结束缓冲期，真正结束后的旧数据不能重新激活仪表。
- 更新源切换保留后台检查偏好；个人修订号比较不把同版本的旧原作者包当成新版本。
- 5/50/500 米距离取整没有回退。
