# CorsairPlay precision.8

改善检查更新的提示与刷新方式，并修复多分辨率 UI 回归发现的布局问题。

## 更新内容

- 未联网时，手动检查更新和查询历史版本直接提示“当前未连接网络，请连接网络后重试”。DNS 失败、连接超时和其他检查失败均显示可理解的提示，不在页面上直接显示英文异常。
- 手动检查期间及结果返回时保留原页面；检查中更新原按钮和状态，发现新版时只替换更新区域，减少整页重建造成的闪动。检查中阻止重复请求，恢复网络后可重新点击检查。
- 修复后台更新检查不识别 `precision.6`、`precision.7` 等短版本名的问题。短版本名和原有数字版本名均可检查更新，未知开发版继续跳过；保留后台调度与联网条件。
- 设置、连接页及手动引导中的长按钮允许按文字内容增高，保留统一最小高度和间距，解决小屏／大字体下多行文字被裁切的问题。
- “强制使用完整设置页面布局”会结合窗口宽度和字号判断是否容得下侧栏与正文。空间不足时暂用单列，保留开关选择，窗口恢复足够宽后可继续使用侧栏。同步更新全部现有语言的设置说明。
- 窄屏首页／连接页的品牌文字保持单行并按可用宽度调整字号，避免换行后被固定高度裁切。

## UI 回归范围

本次新增并运行原生 Android 视图的 Robolectric 截图及布局回归，覆盖：

- 800×480（mdpi）、1024×600（mdpi）、1280×720（xhdpi）、1920×1080（xhdpi）、1920×720（xhdpi）、1024×600（xhdpi）、320×600 竖屏及 400×300 小窗口；另有 1280×720 的阿拉伯语 RTL 配置，共 9 组。
- 每组使用 100% 和 130% 字号，并分别检查设置页的自动布局及强制完整布局开关开启状态。
- 首页、连接设置、5 个手动引导步骤、全部 10 个设置分类、关于页离线提示、手机备份页，以及更新弹窗的发现／下载中／待安装状态，共 594 个界面状态。
- 自动检查文字省略与裁切、控件横向边界和滚动可达性；人工复核代表性原生截图。回归报告包含修复前后截图及明确的测试边界。

这些是原生视图自动化与截图验证，不等同于所有车机固件的实机验证；未连接真实 iPhone，未验证实际 CarPlay 视频、仪表投屏、车辆蓝牙和硬件连接表现，也不据此声称完整无障碍合规。

## 安装与更新

- 版本名 `precision.8`，versionCode `63`，包名 `cn.manstep.phonemirrorBox`。
- 沿用 precision.7 的个人签名与配件认证资源，可覆盖升级同签名个人版并保留数据；新旧 APK 的签名与认证资源一致性均在发布前核对。
- GitHub 标签继续使用 `v0.2.26-precision.8`，以兼容旧个人版的更新识别；应用、发布标题与 APK 文件名使用短版本名。
- 同包名的“第三代CarPlay”参考 APK 使用不同签名，不能直接覆盖安装；本版也不会自动迁移不同包名的早期个人版数据。

发布前执行仓库要求的完整单元测试、三个 Debug 构建及 Lint，以及正式 Release 构建、Lint、独立认证与 APK 校验。APK、源码包和发布标签对应同一提交。
