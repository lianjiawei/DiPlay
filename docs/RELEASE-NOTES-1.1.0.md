# CarPlay 1.1.0

- 在“设置 → 车辆 → 车型背景”选择冒险家、航海家或飞行家。默认继续使用原有冒险家图片；保存后记住选择，首页、设置背景和连接页使用对应车型。
- 三种图片沿用同一场景与构图，更换车型不改变按钮、文字、页面布局或 CarPlay 连接配置，也不需要重连。
- 应用名称、页面品牌文字与 APK 文件名统一为 CarPlay，版本采用 1.1.0。沿用包名和既有签名，版本代码递增为 73，可直接覆盖 1.0.0 及 precision.10 之后的版本并保留设置。

最低 Android 7.1（API 25），继续兼容 Android 8.1。车型选择为装饰性背景设置，不修改配对身份、原车车型识别或林肯硬件功能。

发布验证覆盖选择与取消、重开记忆、原有会话保留、设置备份、横竖屏、大字体与阿拉伯语布局，并执行完整 Android CI、Release Lint 和签名及附件完整性检查。精确结果随发布记录附上。
