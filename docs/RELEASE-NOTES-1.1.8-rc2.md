# CarPlay 1.1.8-rc2

这是 1.1.8 的第二个候选版本，修正 RC1 未真正接通的林肯原车仪表路口进度，并加强重规划和异常传输边界保护。

1. **接通原车仪表进度**：删除无效的 `BargraphSteps` 广播字段，按已核对的仪表 APK 输入契约发送路口身份标识，由仪表使用当前距离与本路口起始距离计算进度。道路名称、距离和转向图标继续沿用原有广播。

2. **重规划和路线切换保护**：下一路口、明确结束、加载路线及重新规划都会建立新的进度基准。重规划期间保留最近成功显示，恢复导航并收到新距离后才重新起算；重复状态、短暂空列表、路名补全和普通定位状态不会反复重置。

3. **丢包、重启与发送异常保护**：同一身份下实际发送的距离保持不增加。仪表重启、首包丢失、距离向上修正以及发送结果不确定时会换用新身份，避免仪表未钳制的计算超过 256。负数、整数极值和异常超远距离仍不会发送。

4. **仪表文本和距离规则保持对齐**：道路名和媒体文字继续按仪表的 19 个 UTF-16 单元安全截断；路口距离继续使用 1 公里内原始米数、100 公里内向下取整到 100 米、更远向下取整到 1 公里的规则。

## 安装与升级

- 支持 Android 7.1（API 25）及以上系统。
- 包名保持 `cn.manstep.phonemirrorBox`，沿用 1.1.8-rc1 的签名时可覆盖安装并保留设置。
- 本版本仍为 RC / Pre-release，建议先在手机或车机上验证仪表显示，再决定是否升级为正式版。

## 验证范围

源码回归通过：shared 1,771 项测试（1 项既有跳过）、common 1,899 项、home 6 项，失败和错误均为零；林肯仪表广播测试在 API 25、27、28、33 共 108 项。三个应用的 debug 构建与 lint、公开源码凭据检查和更新镜像脚本测试均通过。发布时另执行 release lint、签名构建、APK 包名/版本/签名及 SHA-256 校验。

自动测试覆盖真实 iAP2 TLV 解析、快照通知、仪表广播字段和仪表 APK 的进度公式，包括编号复用且距离缩短的重规划、状态与距离分帧、丢包、接收端重启、发送异常、明确结束和断开重连。没有执行视觉截图回归，也不宣称完成实车验收。若导航应用完全不发送结束、Loading 或 Rerouting 信号，同时复用编号且距离不增加，协议输入不足以可靠判断新路线；这只可能影响进度比例，不影响收到的道路名、距离和转向图标。

实现与逆向依据见 [林肯仪表路口进度接口复核](LINCOLN-CLUSTER-PROGRESS.md)。
