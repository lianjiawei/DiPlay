# CarPlay 1.1.8

这是 1.1.8 正式版。它保留 1.1.8-rc2 已验证可在林肯原车仪表显示的路口进度，并修复实车反馈中距离持续减小时进度偶尔重新起算的问题。

1. **稳定原车仪表路口进度**：修复导航、歌词通知和定时保活并发时旧快照晚到的问题。广播距离不再出现 `400 → 125 → 90 → 125 → 80` 这类回退，避免仪表误判为距离回升并把进度刷满；同一输入现在保持 `400 → 125 → 90 → 80`。

2. **补全并发和边界保护**：发送时统一使用最新发布状态。即使新导航通知被其他监听者延迟，定时保活仍会发送最新距离；换路口、导航结束、断开重连和发送锁竞争不会恢复旧导航或重复建立基准。

3. **保持 RC2 的仪表对齐**：继续通过路口身份和距离让原车仪表计算进度；下一路口、明确结束、加载路线和重新规划会建立新基准。道路名称和媒体文字仍按 19 个 UTF-16 单元安全截断，距离仍按原车百度地图精度规则发送。

4. **避免其他字段回退**：迟到的导航快照不会把歌词、媒体状态或剩余里程覆盖成旧值。真实距离向上修正、仪表重启、首包丢失、发送异常、负数和异常超远距离保护保持不变。

## 安装与升级

- 支持 Android 7.1（API 25）及以上系统。
- 包名保持 `cn.manstep.phonemirrorBox`，沿用此前正式版和 RC 版签名，可覆盖安装并保留设置。
- GitHub Release 和国内镜像均提供 APK 与 `SHA256SUMS.txt`，应用继续执行文件校验和 Android 签名校验。

## 验证范围

完整非视觉回归通过：shared 1,795 项（1 项既有跳过）、common 1,899 项、home 6 项，合计 3,700 项，失败和错误均为零；三个应用的 debug 构建和 lint 全部通过。仪表广播测试在 API 25、27、28、33 共 132 项，新增并发场景共 24 项 SDK 检查。

自动测试覆盖旧歌词回调晚到、定时读取被新导航超越、新通知被慢监听者阻塞、发送锁竞争时换路口、导航结束、断开重连、歌词与剩余里程不回退，以及 RC2 已有的重规划、丢包、仪表重启和异常距离保护。发布包另执行 release lint、签名构建、包名、版本、签名及 SHA-256 校验。

按要求未执行视觉截图或模拟器安装回归。RC2 的实车反馈已确认进度能够显示；本正式版针对进度偶发重刷的修正已经过源码和自动化回归，仍需本次发布包的实车测试确认最终效果。

实现、仪表 APK 接收公式和对抗性复现见 [林肯仪表路口进度接口复核](LINCOLN-CLUSTER-PROGRESS.md)。
