# CorsairPlay precision.7

基于个人版 `precision.6`，改善开机与首次安装体验，并移除临时手机日志采集。

## 更新内容

- 首次安装后不再自动进入分步设置引导，启动时直接选择首页，再按自动连接设置继续。需要调整的选项仍可从设置中打开；用户手动打开的引导仍可使用。
- 未保存过对应设置时，开机启动默认开启、打开应用后自动连接默认开启，默认连接方式为 USB。已保存的关闭状态、无线或“上次使用”选择保持优先，不执行强制设置迁移；这些新默认值也适用于旧安装中从未保存过的对应设置项。
- 自动连接开启时，启动流程检测当前 USB 列表，发现已插线的 Apple 设备则优先走有线，不依赖开机后再次收到 USB 插入广播。检测不要求预先授权 USB；后续授权、认证和连接仍走既有流程。
- 已有会话、设置／引导页面、认证配置不可用或 Activity 退出时，不因启动检测强制重连。排队期间再次检查连接状态与设置，避免重复启动；手机已拔掉或 USB 扫描失败时，回退到保存的默认连接方式。
- 移除有线连接时临时启动的手机日志服务及最多两分钟的后台读取。正常连接诊断、配对恢复、256 字节 USB 分块发送和启动超时保护继续保留。

保留仪表路名／歌词完整发送、控制字符过滤、5／50／500 米距离精度及既有音频修复。仪表自身仍可能按显示宽度或固件规则截取文字。本版继续选择性吸收上游 `0.2.27`，不是完整合并。

## 安装与在线更新

- 应用版本名为 `precision.7`，versionCode 为 `62`，包名为 `cn.manstep.phonemirrorBox`。
- 沿用 precision.6 的个人签名与 CarPlay 配件认证资源，可覆盖升级 precision.6 并保留应用数据和已保存设置。
- 更新源仍为 `lianjiawei/DiPlay` 的 GitHub Releases。为兼容旧个人版的更新识别，Git 标签继续使用 `v0.2.26-precision.7`；应用版本名、APK 文件名和发布标题使用 `precision.7`。
- 手动检查更新可立即查询，后台检查沿用原有调度。Android 授权、车机对开机启动的限制仍由系统控制。
- 更早的 `com.corsairplay` 个人版属于不同包名，不自动迁移数据；参考“第三代CarPlay”APK 虽同包名但签名不同，不能直接覆盖。
