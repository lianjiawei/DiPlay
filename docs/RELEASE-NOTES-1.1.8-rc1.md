# CarPlay 1.1.8-rc1

这是 1.1.8 的首个候选版本，重点验证林肯原车仪表的导航和媒体信息对齐。

1. **仪表文本对齐**：道路名称、歌曲标题、歌手和音源名称按原车仪表的 19 个 UTF-16 单元上限发送，并在 Unicode 字符边界安全截断，避免长文本越界或拆开表情、扩展字符。

2. **路口距离对齐**：改为与原车百度地图一致的精度规则：1 公里内保留原始米数，100 公里内向下取整到 100 米，更远距离向下取整到 1 公里；无效负数及异常超大值不会发送到仪表。

3. **路口进度广播尝试（后续确认未接通）**：此 RC 向导航广播附加了 `BargraphSteps`，但后续完整追踪仪表接收代码确认：该字段属于仪表内部的下游输出，广播入口并不读取它。因此不能将此 RC 描述为已实现路口进度。

## 安装与升级

- 支持 Android 7.1（API 25）及以上系统。
- 应用包名保持 `cn.manstep.phonemirrorBox`，使用与 1.1.7 相同的发布签名时可覆盖安装并保留设置。
- 本版本标记为 RC / Pre-release，适合先在手机或车机上验证后再升级为正式版。

## 验证范围

完整源码回归已通过：共享层、公共层和主页单元测试，三个应用的检查，以及三个调试包构建均成功。新增测试覆盖文本截断、负数和整数边界、路线切换、重规划、距离抖动、短暂空帧及进度重复广播。

上述 RC 测试仅验证了 DiPlay 发送内容，没有覆盖真实接收端的输入契约。2026-10-25 的复核确认需要通过 `latitude` / `longitude` 双精度字段识别路口，再由仪表根据距离计算进度；后续修正见 [仪表进度接口复核](LINCOLN-CLUSTER-PROGRESS.md)。本文保留已发布 RC 的历史事实，不代表修正已发布或已通过实车验证。
